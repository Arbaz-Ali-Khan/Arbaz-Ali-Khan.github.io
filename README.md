# Arbaz Ali Khan — Portfolio

Responsive static portfolio built with HTML, CSS, and vanilla JavaScript for GitHub Pages.

## Site files
- `index.html` — sections, experience, project cards, case study
- `styles.css` — responsive styles and layout
- `script.js` — mobile navigation and footer year
- `assets/profile-placeholder.svg` — replace with your professional portrait
- `assets/favicon.svg` — site favicon

## Add your photo
Upload a portrait as `assets/profile.jpg`, then update the image source in the hero section of `index.html` from `assets/profile-placeholder.svg` to `assets/profile.jpg`. A 4:5 portrait crop works well.

## Enable GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for the Pages deployment to complete.

Expected site URL: https://arbaz-ali-khan.github.io/
